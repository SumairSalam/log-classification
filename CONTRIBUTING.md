# Contributing

Thanks for your interest in contributing! A few guidelines:

- Open an issue for significant feature requests or bugs before implementing big changes.
- Follow the existing project coding style; run `ruff` and `black` before committing.
- Add tests for new features or bug fixes (tests live in `/tests`).
- Keep commits small and focused; use meaningful commit messages.

If you'd like me to add a GitHub Actions workflow for PR checks or help write tests, I can do that — tell me what you'd like next.
